## Project Overview

This project was developed as a practical application of front-end web development concepts. It focuses on building a functional and visually appealing website, with an emphasis on responsive design, interactive elements and straightforward navigation. The project combines HTML, CSS and JavaScript to create a consistent experience across desktop and mobile devices.

---

## What I Implemented

I used HTML5 to structure the website and organise its content into clearly defined sections. I then applied CSS3 to control the visual presentation, including layouts, styling and responsive behaviour, ensuring that the website adapts to different screen sizes.

I also incorporated JavaScript to introduce interactive elements and dynamic functionality, making the website more engaging and responsive to user actions. Throughout the project, I focused on maintaining a clean interface, consistent styling and intuitive navigation.

---

## Key Features

- **Responsive design:** Adapted the website layout for desktop and mobile devices.
- **Interactive elements:** Used JavaScript to add functionality and respond to user actions.
- **Modern user interface:** Created a clean and visually appealing design.
- **Structured HTML:** Organised website content using HTML5.
- **Custom CSS styling:** Designed layouts and visual elements using CSS3.
